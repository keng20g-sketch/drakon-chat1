Drakon Chat - Native Android edition
====================================
تمت إزالة Kivy وPython بالكامل. التطبيق Android Native Java.

الحساب الإداري الافتراضي:
البريد: admin@drakon.com
كلمة السر: Admin123

البناء محلياً:
1) افتح المجلد DrakonChat_Native في Android Studio.
2) نفّذ Build > Build APK(s).
3) ملف APK سيكون داخل app/build/outputs/apk/debug/app-debug.apk

البناء على GitHub:
1) ارفع محتويات DrakonChat_Native إلى مستودع GitHub.
2) ادخل تبويب Actions.
3) شغّل "Build Drakon Chat APK" أو اعمل push إلى main/master.
4) بعد انتهاء البناء افتح الـworkflow ثم Artifacts ونزّل DrakonChat-debug.

ملاحظة:
لا توجد مكتبة Kivy أو Python في المشروع.
